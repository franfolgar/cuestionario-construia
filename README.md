# Cuestionario Operativo ConstruIA

Aplicación web interactiva para constructores, jefes de obra y reformistas. Permite calibrar los parámetros de cálculo (software de presupuestos, desgloses, márgenes de beneficio industrial, mano de obra, tratamiento de materiales y subidas de precios) para la plataforma **ConstruIA**.

## Características
- 📱 **100% Responsive:** Diseñado para ordenador, tablet y smartphone.
- 💾 **Autoguardado en local (localStorage):** No se pierden las respuestas aunque se cierre el navegador.
- 📄 **Exportación directa a PDF:** Genera un informe maquetado profesional listo para descargar o imprimir.
- 💬 **Compartir por WhatsApp o Portapapeles:** Envío rápido de respuestas en un solo clic.
